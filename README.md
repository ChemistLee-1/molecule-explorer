# 분자 탐험대

집 · 학교 · 공원에 숨은 화학 물질을 찾아 도감을 완성하는 모바일 웹 게임입니다.

- 장소와 구역을 고른 뒤, 그 구역에 있는 실제 물건(식초병, 분필 등)을 카메라로 비춥니다.
- 물건을 알아보면 그 속의 물질이 나타나고, 길게 눌러 분석하면 분자 구조가 드러나 도감에 등록됩니다.
- 물건 인식은 휴대폰 안에서 이루어지며 사진은 밖으로 전송되지 않습니다. 처음 한 번 인식 모델(약 90MB)을 내려받습니다.
- 물질 64종, 발견 장소 72곳, 특별 안전 카드 1장이 들어 있습니다.

## 실행

설치나 빌드 과정이 없습니다. 폴더를 그대로 웹 서버에 올리면 됩니다.

PC에서 확인하려면 폴더에서 아래 명령을 실행하고 `http://localhost:8123` 을 엽니다.

```bash
py -m http.server 8123
```

휴대폰의 카메라와 자이로 센서는 HTTPS 주소에서만 동작합니다. GitHub Pages에 올리면 HTTPS가 자동으로 적용됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면 구조와 디자인 |
| `js/data.js` | 물질·장소 데이터 (설명을 고치려면 이 파일만 수정) |
| `js/chem.js` | 분자 연결 정보로 3D 구조를 계산 |
| `js/render.js` | 분자 모형 뷰어 |
| `js/app.js` | 카메라 인식, 채집, 도감 |
| `js/vision-worker.js` | 이미지 인식 모델 실행 (CLIP ViT-B/32, transformers.js) |
| `js/embeds.js` | 물건별 인식 기준 데이터 (자동 생성) |
| `tools/prompts.json` | 물건별 인식 문구. 고친 뒤 `tools/build-embeds.mjs` 로 `js/embeds.js` 를 다시 만듭니다 |
| `tools/test.html` | 사진으로 인식 결과를 확인하는 개발용 페이지 |
| `일상생활_화학물질_장소별.md` | 데이터의 원본 자료 |

## 참고

물건 인식은 겉모습으로 판단하므로 소금·설탕처럼 비슷하게 생긴 것은 구분하지 못할 수 있습니다.
인식이 너무 까다롭거나 느슨하면 `js/app.js` 의 `STRONG`, `WEAK` 값을 조정합니다.

분자 모형의 원자 종류·개수·결합은 화학식과 일치하지만, 결합 각도와 입체 모양은 근사값입니다.
고분자, 결정, 엽록소 등 일부 물질은 단순화한 모형이며 카드에 표시되어 있습니다.
